  Funcionalidades Implementadas

  Tienda Publica

  - Home con hero, categorias y productos destacados
  - Catalogo por categoria con filtros
  - Detalle de producto con galeria
  - Carrito lateral (drawer)
  - Checkout con multiples metodos de pago

  Panel Admin

  - Dashboard con KPIs (ventas, ordenes, stock bajo)
  - CRUD de productos
  - Gestion de ordenes
  - Cierres diarios con exportacion CSV
  - Reportes de ventas con graficos

  API y Backend

  - Integracion con Supabase (Postgres + Auth + Storage)
  - Integracion con Stripe para pagos
  - Webhooks para confirmar pagos y actualizar stock
  - Preparado para MercadoPago y wallets locales (Nequi/Daviplata)

  Para Iniciar

  1. Instalar dependencias:
  cd PROYECTO_YB_MOTOCOM/apps/web
  npm install

  2. Configurar variables de entorno:
  cp .env.example .env.local
  # Editar con tus credenciales de Supabase y Stripe

  3. Crear tablas en Supabase:
    - Ejecutar infra/supabase/migrations.sql en SQL Editor
  4. Iniciar desarrollo:
  npm run dev

  La aplicacion estara en http://localhost:3000

  Para Levantar Todo

  Solo necesitas un comando ya que es una sola aplicacion:

  cd C:\Users\ACER\Downloads\PROYECTO_YB_MOTOCOM\apps\web

  # 1. Instalar dependencias
  npm install

  # 2. Configurar variables de entorno
  copy .env.example .env.local
  # Editar .env.local con tus credenciales

  # 3. Levantar (frontend + backend juntos)
  npm run dev

  Esto levanta:
  - Frontend: http://localhost:3000 (tienda)
  - Admin: http://localhost:3000/admin (panel)
  - API: http://localhost:3000/api/* (endpoints)

  Antes de Levantar - Configurar Supabase

  1. Crear cuenta en https://supabase.com
  2. Crear un nuevo proyecto
  3. Ir a SQL Editor y ejecutar el contenido de infra/supabase/migrations.sql
  4. Ir a Settings > API y copiar las credenciales a .env.local:

  NEXT_PUBLIC_SUPABASE_URL=https://tu-proyecto.supabase.co
  NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGc...
  SUPABASE_SERVICE_ROLE_KEY=eyJhbGc...

  Si necesitas un backend separado tradicional (Express, NestJS, etc.) puedo crearlo, pero la        
  arquitectura actual con Next.js + Supabase es mas simple y escalable.
